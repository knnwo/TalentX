# TalentX

A small World of Warcraft addon that adds a red X next to each talent loadout
in the loadout dropdown, so you can delete builds with one click.

## Features
- Red X on every loadout row (except Starter Build, New Loadout, Import and Share)
- Alt + Left-click required to delete, so you don't remove a build by accident
- The currently selected loadout is protected
- Hover tooltip showing which loadout you're about to delete

## Usage
Open the talents window, open the loadout dropdown, and Alt + Left-click the X
next to a loadout.

## Commands
- `/talentx alt` toggles the Alt requirement on or off
- `/talentx debug` prints debug info about the menu rows

## Installation
Copy the `TalentX` folder into `World of Warcraft/_retail_/Interface/AddOns/`.
